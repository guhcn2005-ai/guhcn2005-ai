## 📌 Projetos em destaque

### 📖 StoryNodes

Uma plataforma de histórias interativas desenvolvida como projeto próprio.

A ideia do projeto é explorar uma experiência de leitura em que as decisões do usuário podem influenciar o desenvolvimento da narrativa.

O projeto possui frontend e backend desenvolvidos separadamente, permitindo explorar conceitos de desenvolvimento Full Stack, APIs e persistência de dados.

**Tecnologias:**  
`JavaScript` `Node.js` `API REST` `SQL`

🔗 [Frontend](https://github.com/guhcn2005-ai/story_nodes-v1)  
🔗 [Backend](https://github.com/guhcn2005-ai/story_node_api)

### 🍔 Urban-Burguer

Aplicação web desenvolvida para simular operações de um sistema de gerenciamento de produtos, usuários e pedidos.

O projeto foi desenvolvido explorando a integração entre frontend, backend, API e banco de dados.

**Tecnologias:**  
`HTML` `CSS` `Bootstrap` `JavaScript` `Node.js` `SQL`
